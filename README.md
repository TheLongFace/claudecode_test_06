# 偉人伝説 ○× トロッコ

トロッコに乗って洞窟を進み、分岐ごとに出る「偉人の伝説」○×クイズに答えるスマホ向けブラウザゲーム。

- ○ なら左のレール、× なら右のレール。分岐の先は中が見えないトンネルになっていて、抜けた瞬間に正解か脱線かがわかる。
- ステージごとに落石・溶岩の噴き上げ・サメ・雷・火炎トラップなどの危険演出あり。
- スタート画面でコースを選べる：全偉人ミックス／戦国武将／芸術家／変な人／文豪／学者・発明家／生きもの（コース定義は `questions.js` 末尾の `COURSES`）。
- 10問連続正解でクリア。難易度は1問目から★1→★5へ上がる。
- ステージ：暗闇の洞窟 → 灼熱の地底 → 深海トンネル → 天空レール → 黄金の神殿
- 問題は `questions.js`（Wikipediaに載っている逸話をもとに296問）。× は別の偉人のエピソードとの入れ替え、または内容の一部を変えたもの。

`index.html` をブラウザで開けば遊べます。

生きものコースは生態クイズ（`questions.js` の `BIO_QUESTIONS`）。問題ごとに、その生きものが住む場所（深い森・サバンナと砂漠・氷の世界・深い海・洞窟と地中・大空）へ景色が変わり、画面の色も緑系になる。
